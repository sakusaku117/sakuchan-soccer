# さくちゃんサッカー

▶ **あそぶ:** https://sakusaku117.github.io/sakuchan-soccer/

6歳から遊べる、8人制のサッカーゲームです。ドリブルで相手をかわして、シュートでゴールをねらいます。

`index.html` をブラウザで開くだけで遊べます。インストールや通信は不要です。スマホ・iPadは横向きで遊びます。

## 遊び方

- タイトル画面で前半の長さ(3分・5分・8分)と、相手の強さ(🐣やさしい・🐶ふつう・🦁つよい)を選びます。後半も同じ長さです。
- 黄色い▼がついた選手を動かします。ボールに近づくと、ボールが足もとにつきます。
- 操作する選手は、ボールに一番近い味方に自動で切りかわります。パスを出すと、受ける選手に切りかわります。
- パスは、向いている方向にいる味方へ自動で出ます。
- 相手がボールを持っているときは「とる」でボールをうばえます。キーパーは自動で動きます。
- 相手のゴールに入れると1点です。前半・後半が終わったときに点が多いチームの勝ちです。

## せってい

タイトル画面の「⚙ せってい」で変えられます。選んだ内容はこの端末に保存されます。

| こうもく | 内容 |
|---|---|
| ユニフォームの いろ | 自分のチームの色を6色から選ぶ |
| そうさする せんしゅの きりかえ | じどう:ボールに近い味方に自動で切りかわる/じぶんで:「きりかえ」ボタンで切りかえる |
| キーパー | おまかせ:自動で守る/じぶんで とめる:相手がシュートすると少しゆっくりになり、「とめる!」ボタンで飛びつく |
| いどうの おてつだい | あり:指をはなしていても、選手が自動でボールを追いかける(ボタンを押すだけで遊べる) |
| おと | 音のあり・なし(右上の🔊でも切りかえられる) |

## スマホ・iPadの操作

- 画面の左半分をさわって指を動かす:選手が動く(大きく動かすとダッシュ)
- 「パス」ボタン:向いている方向の味方へパス(相手がボールを持っているときは「とる」)
- 「シュート」ボタン:ゴールに向かって強くける(相手がボールを持っているときは「きりかえ」:ボールに近い別の味方を動かす)
- 左上の「II」:一時停止

## キーボード操作

| キー | うごき |
|---|---|
| `←` `↑` `↓` `→`(`W` `A` `S` `D` も可) | 選手を動かす |
| `Shift` | 押しながら動くとダッシュ |
| `スペース` | パス(守るときは、ボールをとる) |
| `Enter` | シュート(守るときは、操作する選手をきりかえる) |
| `Esc` | 一時停止 |

キーパーを「じぶんで とめる」にしたときは、`スペース` か `Enter` で飛びつきます。

メニューでは `↑` `↓` で段を、`←` `→` でボタンを選び、`Enter` で決めます。
